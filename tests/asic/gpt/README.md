# Dedicated GPT kernels

Run `python3 scripts/asic/gpt.py` from the repository root. The command builds actual SystemVerilog with Verilator, generates two existing synthetic N2/H128/heads2/FF512 reference inputs, drives the RTL, and writes `build/experiments/asic/gpt/result.json`. `--output` selects an isolated output directory and `--verilator` selects the Verilator executable.

The build keeps Verilator warnings fatal except for module/filename naming differences and unused upper address bits (`DECLFILENAME` and `UNUSEDSIGNAL`).

`GptAsic` instantiates three independent units: `GptNorm` for one H128 LayerNorm row, `GptSoftmax` for one two-column causal Softmax row, and `GptVector` for GELU, requantization, and saturated residual addition on up to 1024 words. All inputs and affine parameters enter through the runtime write port. No expected output is embedded in the DUT. The fixed shapes bound storage and control but do not specialize runtime input values.

The runner checks both layers' LayerNorm rows, both heads' Softmax rows, six projection requantizations, PV requantization, GELU and both residual additions from each existing reference input. These are kernel tests using reference-generated intermediate inputs; they do not execute Gemmini or prove a complete GPT pipeline. Additional arithmetic cases cover constant/full-range LayerNorm, all INT8 GELU inputs, signed requantization limits/ties, and causal masking with large score differences. The two workload inputs and arithmetic cases execute without resetting the accelerator between commands.

LayerNorm supports seven individually launched phases or one fused launch: sum, mean, squares, variance, square root, affine, and final requantization. Softmax supports three individually launched phases or one fused launch: maximum, exponent/sum, and normalization. Both modes retain intermediate arrays/statistics locally, so their transfer counts are identical. This isolates launch coalescing; it does not establish a reduction in DRAM or DMA traffic. The staged commands are issued immediately after completion, so the measured difference is only the command-cycle cost of this standalone interface, not software launch overhead.

Execution cycles count clock edges from the accepted start command through `done`, including one start edge per launch, and exclude input loading and result checking. Transfer counters count actual 32-bit fixture-port writes and reads, including LayerNorm gamma/beta reloads for each row; they are not packed INT8 or SoC bus measurements. Result records identify each tested kernel, mode, input, launch count, output count and mismatch count.

LayerNorm affine normalization, Softmax normalization and vector requantization use a shared module implementation of 32-step restoring division, instantiated independently in each unit. Constant divide-by-four GELU and residual arithmetic retain direct datapaths. Local arrays use combinational reads. Synthesis must charge the actual cells and qualify timing; no SRAM mapping, clock-frequency guarantee, area advantage or complete-system performance claim follows from the RTL cycle counts. Legal commands use units 0–2, LayerNorm phases 0–6, Softmax phases 0–2, vector operations 0–2, count 1–1024, and a nonzero divisor. Source values and affine parameters follow `scripts/block_math.py` and the existing fixture's numeric contract.
